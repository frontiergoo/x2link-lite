# データ契約・転送決定表

## 所有範囲と識別子

初期は単一ワークスペースを管理された個別アカウントで運用する。API/画面はログイン利用者の所属から対象ワークスペースを決め、フォームの入力で所有者を切り替えない。リンクの不変IDはUUID、公開別名はホストとパスの組で一意。新規スラッグは小文字英数字・ハイフン・下線の3〜64文字。自動生成は紛らわしい0/O/1/l/Iを含まない9文字。

公開済みURLは転送先変更・履歴復元で変更しない。下書き・停止・アーカイブも別名を予約する。完全削除ではUUIDと別名を残し、内容・設定の版・解析を消去する。削除済みリンクは編集・復元・再公開できない。

## 転送決定表

|順番|条件|結果|
|---|---|---|
|1|ホスト＋パスが未知|404、安全な状態ページ|
|2|削除済み|410、削除済み案内|
|3|不正利用停止／全体緊急停止／一時停止／アーカイブ|410、停止案内|
|4|下書き|404、未公開案内|
|5|開始より前、または終了以降|個別期間外先→ワークスペース既定期間外先→410|
|6|期間内かつスマートフォン、端末別先あり|端末別先へ302|
|7|期間内、その他|既定先へ302|
|8|選択された転送先の安全性確認に失敗|503、安全な案内|
|9|DBから設定を読めない|503、安全な案内|

UTC保存、日本時間で入力・表示する。開始を含み終了を含まない。GET/HEAD以外を転送しない。公開リクエストのクエリを転送先へ引き継がない。すべての応答はno-store。登録・再公開・復元時はURL構文とA/AAAAの公開アドレスを検査する。停止はDNS障害でも可能。公開転送のリクエスト内でDNSや転送先ページを取得しない。P1の到達監視を追加する場合はDNS再束縛を含む送信制限を別途設計する。

## 更新・監査・復元

versionは1から単調増加する。更新は対象ID・所有範囲・期待versionを条件にして競合を検出する。設定のスナップショットは日時をUTCに正規化する。操作者・変更項目・時刻・版を監査に残し、メモやURLパラメータの値を監査の差分にコピーしない。確認画面ではクエリ・フラグメントとメモ本文を隠して変更項目を示す。復元も現在の安全性検査と所有範囲確認を行う新しい版とする。不正利用停止は過去の版から復元しても解除しない。

## 本文変換

プレーンテキスト100,000文字、URL候補100件まで。候補の開始・終了位置を保持し、選択した箇所だけを末尾から置換する。日本語の句読点・括弧をURL末尾から分離し、クエリ・フラグメントは保持する。位置別／同一URLの共通リンクを選べる。任意UUIDの冪等キーと入力内容の指紋で再試行の重複を防ぐ。同じキーで内容を変えた場合は拒否する。リンクは下書きで一括作成し、別操作で公開する。

本文は標準で保存しない。本文の任意保存を選んだ場合は7日間。再開用には生成したリンクの対応を保存する。完全削除時は残存を防ぐためワークスペースの変換結果を消去する。最終的な差分・変換結果を確認してから配布する。

## 解析と保持

イベントUUIDを主キーとして重複を拒否し、処理済みフラグとDBトランザクションで集計の再試行を安全にする。判定ルールv1は端末推定、既知のボット・プレビュー・メールスキャナー識別子、GET/HEAD、転送応答状態を用いる。人のクリック、ユニーク人数、転送先読込、売上を保証しない。配信直後の検査集中は完全に識別できないため、疑わしい増加を利用者が確認できる日次・端末・参照元・位置の集計を示す。

転送リクエスト数は登録リンクへの対象GET/HEAD（停止等を含む）、転送成功数は302応答、推定有効クリックは302を返したGETから識別できる自動取得を除外した値。不明パスは特定のリンクへ帰属させない。日付はAsia/Tokyo、参照元はドメインのみ、不明を残す。イベント送信失敗はログで監視し、期間の欠損を説明する。遅延・ワーカー最終実行・未処理件数を画面に表示する。

詳細30日、集計397日（約13か月）、操作者の監査180日、本文結果7日。未集計イベントは運用者が確認するまで削除しない。リンク設定の版は存続中保持する。バックアップの失効と削除要求の再適用は本番運用基盤で管理する。

## エクスポートv1

JSONオブジェクト：format=x2link-export-v1、exported_at=UTCのISO8601、records=Django標準JSON形式の配列（model、pk、fields）。対象はリンク、公開別名、設定の版、キャンペーン、日次集計。アカウントのパスワード・MFA・セッションは含めない。URLのクエリやメモには機密情報があり得るため、取得したファイルは利用者が安全に保管する。F17の一括編集用CSVとは目的が異なる。

## 条件付きの旧版移行

必要性・現行ドメインの管理権・対象件数・旧環境の稼働状況が未確認。旧ソースを実装環境に持ち込まず、調査側が中立なJSON契約に変換した入力から移行する。移行別名は元の大小文字を保持し、元ID・末尾スラッシュ・.htmlの別名を検査する。終了時刻は調査側が日本時間の旧形式から終了を含まないUTCへ変換する。既定転送の経過措置、未知データ、予約語競合、削除済みIDは利用者が判断する。実データ未提供のため互換・切替・ロールバックの完了は未検証。
