- バックアップ復元後のワークスペース・リンク・別名・版・監査を照合し、実HTTPで正しい302とno-storeを確認。
- 依存監査で固定した実行時依存12件すべてを直接監査して既知脆弱性0件。これは全脆弱性の不在を保証するものではない。
- Djangoシステムチェック、未生成マイグレーションの不在、Ruffの未定義・未使用検査、Git差分の空白検査を実施。
- 元プロジェクトでDocker構成とPostgreSQL負荷を検証。Lite版はDockerとPostgreSQLを含まず、格安サーバー上の負荷試験は未実施。
